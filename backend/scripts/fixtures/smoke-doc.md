# Manual do Laboratório Aurora

O Laboratório Aurora fica no bloco C da Escola Municipal Horizonte.

## Horário de funcionamento

O laboratório funciona de segunda a sexta-feira, das 8h às 17h.

## Senha do armário de reagentes

A senha do armário de reagentes do Laboratório Aurora é **girassol-4721**.
Ela é trocada todo início de semestre pela coordenação pedagógica.

## Responsável

A professora responsável pelo laboratório é Marta Quintana.
